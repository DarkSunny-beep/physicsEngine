# OverView
The majority of the core engine code in this repository is based on Ian Millington's book, *Game Physics Engine Development*.  
However, it also includes various custom programs and demonstrations where I have personally refactored the code, optimized structures, and added new features.  

  
In this README, I will focus only on explaining the core code and providing any noteworthy additional details.
